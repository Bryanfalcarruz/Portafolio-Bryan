## Proyecto destacado

### File Organizer: Python, Docker y AWS con Terraform

[Ver proyecto y estado técnico](Proyecto_DevOps/README.md)

Organizador de archivos por extensión con interfaz de línea de comandos, Dockerfile e infraestructura modular en AWS. Incluye documentación de uso y capturas del aprovisionamiento.

| Estado | Alcance |
| --- | --- |
| Implementado en el repositorio | CLI en Python, Dockerfile y módulos Terraform de red, EC2, ECR y bootstrap S3/DynamoDB. |
| Integración parcial | Arranque de EC2 con Docker e intento de descarga y ejecución desde ECR; falta validar el flujo completo y los argumentos del contenedor. |
| Pendiente | Activar correctamente el backend remoto, verificar la publicación en ECR y la ejecución de la aplicación, ampliar observabilidad e incorporar CI/CD. |

Las capturas documentan prácticas realizadas; no garantizan que los recursos sigan activos. El estado detallado y las limitaciones se mantienen en el README del proyecto.
